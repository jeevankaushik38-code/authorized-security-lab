Testing must not begin until written authorization and scope are confirmed.

## 2. Permitted Techniques
- Review the lab documentation and asset inventory.
- Perform non-destructive reconnaissance on explicitly authorized lab assets.
- Validate security issues using safe, controlled methods within the isolated lab.
- Document findings and recommend remediation.

## 3. Explicit Exclusions
- Denial-of-service testing.
- Destructive payloads or system damage.
- Persistence mechanisms.
- Credential reuse.
- Third-party targets.
- Uncontrolled data extraction.
- Any asset not explicitly authorized.

## 4. Testing Window and Stop Conditions
- Start date and time: [To be approved]
- End date and time: [To be approved]
- Emergency contact: [Enter authorized contact]
- Rate limits: Use conservative rates approved by the lab owner.
- Stop immediately if an unexpected service disruption, unintended data exposure, or out-of-scope system access occurs.
- Resume only after the lab owner authorizes it.

## 5. Evidence Handling
- Collect only the minimum evidence necessary.
- Use synthetic or dummy data wherever possible.
- Redact secrets, credentials, and personal information.
- Store evidence securely with access limited to authorized people.
- Deletion date: [Enter approved retention/deletion date].

## 6. Reporting
For every finding, record:
- Finding ID and affected asset.
- Severity and rationale.
- Safe reproduction steps.
- Potential impact.
- Redacted evidence.
- Recommended remediation.
