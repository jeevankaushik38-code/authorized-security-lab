# Authorized Security Lab

## Project Overview
This repository documents an authorized security lab, its asset inventory, rules of engagement, data flows, and STRIDE threat model.

## Scope
Testing is limited to assets explicitly approved in the asset inventory.

## Safety
No denial of service, destructive payloads, persistence, credential reuse, third-party targets, or uncontrolled data extraction is permitted.

## Project Deliverables
- Asset inventory
- Rules of engagement
- Data-flow diagram
- STRIDE threat model

## Status
Documentation in progress.
